Why this is a sidecar and not an in-file header
-----------------------------------------------
The other recovered artefacts in this package (scripts/reconstructed/*.py) carry
their provenance as a leading comment block. FASTA has no comment syntax that
modern parsers accept -- a '#' or ';' preamble is read as sequence or raises an
error in Biopython, samtools, HMMER and BLAST. Embedding a header would corrupt
the file for its intended use.

The FASTA is therefore held byte-verbatim and its provenance recorded here, in a
sidecar of the same basename. This is a deliberate deviation from the header
treatment applied to the .py files, made so the sequence file remains parseable.

Interpretation caveat
---------------------
The filename "defensins" reflects a working hypothesis formed during that
interactive session. It is NOT an annotation, and no defensin family assignment
was ever made:

  - No HMM, profile, or family-level search placed either sequence in a defensin
    family.
  - InterProScan returned NO Pfam, PANTHER, Gene3D, SUPERFAMILY or CDD signature
    for MSTRG.31255.1 -- only Phobius/SignalP/TMHMM features.
  - The comparison was a visual cysteine-position listing produced by
    scripts/reconstructed/heroGene01_cysteine_comparison_MSTRG31255.py, not an
    alignment. That script's own fallback path ran only when clustalw and muscle
    were both unavailable, which was the case -- neither is installed.

Treat the filename as a label from an exploratory session, not as evidence.
